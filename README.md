# E-Waste Image Classification Using CNN

## 📌 Project Overview

This project develops a Convolutional Neural Network (CNN) based image classification system for identifying different categories of electronic waste (e-waste).

The objective is to investigate the application of deep learning and computer vision for automated identification and classification of e-waste components.

---

## 🎯 Objectives

- Develop an image classification model for e-waste components.
- Perform exploratory data analysis and dataset preprocessing.
- Train a Convolutional Neural Network (CNN).
- Evaluate the trained model on unseen test images.
- Develop a reproducible workflow for e-waste image classification.
